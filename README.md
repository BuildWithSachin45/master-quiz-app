🧠 Master Quiz

Master Quiz is a free, interactive quiz application designed for
learning, practice, and fun. It can be used directly in a web browser
and also includes an Android APK version for mobile devices.

🌐 Live Web App:
https://buildwithsachin45.github.io/master-quiz-app/

✨ Features

🎯 Customizable Quizzes -- Choose the number of questions and
quiz settings.

👤 Single Player Mode -- Take quizzes individually.

👥 2-Player Pass & Play Mode -- Two players can play on the same
device.

📚 Multiple Categories -- Questions are available across
different subjects and topics.

🎚️ Difficulty Selection -- Choose from available difficulty
levels.

⏱️ Quiz Timer -- Complete quizzes within the selected time.

🔀 Randomized Questions -- Questions are randomized for a
different experience.

🔊 Sound Effects -- Audio feedback for correct and incorrect
answers, with mute/unmute control.

🏆 Detailed Results -- View score, correct answers, incorrect
answers, percentage, and performance.

📱 Mobile Friendly -- Responsive design works on phones,
tablets, and desktops.

📲 Android APK -- Use Master Quiz as a standalone mobile
application.

🆓 Free to Use -- No payment or subscription is required.

🎮 How to Use

Open the Live Web App.

Click Start Quiz.

Select your game mode.

Enter the player name(s).

Select categories/subcategories.

Choose the difficulty level.

Select the number of questions.

Start the quiz.

Answer the questions before the timer ends.

View your final results and score.

For 2-player mode, players can take turns answering questions on the
same device.

📱 Android App

Master Quiz is also available as an Android APK.

The APK is included in this repository as:

MasterQuiz.apk

You can install it on a compatible Android device and use the quiz as a
standalone mobile app.

Note: Android may ask you to allow installation from the
browser/file manager if the APK was downloaded outside the Google Play
Store.

🌐 Run the Project in a Browser

This is a static web application, so no backend server or database is
required.

Option 1 --- Use the Live Version

Simply open:

https://buildwithsachin45.github.io/master-quiz-app/

Option 2 --- Run Locally

Clone the repository:

git clone https://github.com/buildwithsachin45/master-quiz-app.git

Open the project folder and launch index.html in a web browser.

For the best local development experience, you can also use VS Code
Live Server or another local HTTP server.
